1.1.1-ballot.2026-09
@@@@@@@@@@@@@@@@@@@@@

Version 1.1.1-ballot.2026-09 is a ballot release that modernizes the Cat-VRS build
pipeline and refreshes its imported dependencies. There are no changes to the set of
Cat-VRS product features or to the Cat-VRS class schemas.

Dependencies
############

- The Cat-VRS schema identifier (``$id``) is now
  ``https://w3id.org/ga4gh/schema/cat-vrs/1.1.1-ballot.2026-09.1/...``.
- Imported schemas were updated to the 2026-09 ballot line:
  :ref:`VRS <imported>` ``2.1.1-ballot.2026-09.1`` and GKM Core ``1.2.1-ballot.2026-09.1``.

Supporting changes
##################

The following **supporting** changes were made to Cat-VRS that do not impact the
Cat-VRS data model:

- Adopted the modernized GKM metaschema processor (``ga4gh.gkm.metaschema`` 0.4.1), with
  which the source YAMLs are compiled (``source2classes`` / ``source2splitjs`` / ``y2t``).
- Cat-VRS now generates and owns the documentation definitions for its imported VRS and
  GKM Core classes locally, rather than depending on the submodule's pre-generated
  definitions. Imported VRS class pages now link to the full definition in the latest
  `VRS specification <https://vrs.ga4gh.org/en/latest/>`_.
