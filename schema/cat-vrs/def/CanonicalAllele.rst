**Computational Definition**

A canonical allele is defined by an :ref:`Allele` that is representative of a collection of congruent Alleles, each of which depict the same nucleic acid different underlying reference sequences. Congruent representations of an Allele often exist across different genome assemblies and associated cDNA transcript representations.
