**Computational Definition**

Some categorical variation concepts are supported by custom nomenclatures or text-descriptive representations for which a categorical variation model does not exist. DescribedVariationConstraint is a constraint class that adds requirements and contextual semantics to the `lnamebel` and `description` fields to indicate how a categorical variation concept should be evaluated for matching variants.
